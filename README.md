# M&N Civil Planner

An elegant, modern web application for organizing civil wedding celebrations, roadtrip itineraries, budget management, private notes, and vows vaults.

## Features

- **Civil Itinerary Planner**: Chronological event management connected with dynamic monochrome timeline roadlines.
- **Couple Vault**: Shared task lists, private notes pad, and passcode-protected vows vault.
- **Budget Calculator**: Real-time breakdown for ceremony fees, restaurant reservations, and shared expenses.
- **Interactive Calendar**: Event display integrated directly into the October grid.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
